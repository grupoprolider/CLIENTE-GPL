## 🚀 Cómo publicarlo en GitHub Pages para abrirlo en el celular

1. Subí los archivos de esta carpeta a un repositorio de GitHub (`index.html`, `styles.css`, `app.js`, `manifest.json` y `LOGO-gpl.png`).
2. En tu repositorio de GitHub, entrá a **Settings** → **Pages**.
3. En **Branch**, elegí `main` (o `master`) y guardá (**Save**).
4. En 1 minuto GitHub te dará el enlace (ej. `https://tu-usuario.github.io/app-clientes-gpl/`).
5. Abrí ese link desde el navegador de tu teléfono (Chrome en Android o Safari en iPhone). Podés elegir **"Agregar a la pantalla de inicio"** para que se instale con el ícono de **GPL** y abra a pantalla completa sin barras del navegador.
